# Toolchain Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate use-undo from yarn/microbundle/jest to pnpm/vite/vitest.

**Architecture:** Replace package manager, build tool, and test runner in sequence. Each task produces a working state before the next begins. The library source code (`index.ts`) is not modified — only tooling config changes.

**Tech Stack:** pnpm, vite, vite-plugin-dts, vitest, @vitest/coverage-v8, jsdom

**Spec:** `docs/superpowers/specs/2026-03-25-toolchain-migration-design.md`

---

### Task 1: Migrate yarn → pnpm

**Files:**
- Delete: `yarn.lock`
- Create: `pnpm-lock.yaml` (generated by `pnpm import`)
- Modify: `package.json` (scripts only)
- Modify: `.husky/pre-commit`

- [ ] **Step 1: Import yarn.lock into pnpm**

Run:
```bash
pnpm import
```
Expected: `pnpm-lock.yaml` created from `yarn.lock`.

- [ ] **Step 2: Delete yarn.lock**

Run:
```bash
rm yarn.lock
```

- [ ] **Step 3: Update scripts in package.json**

Change these scripts:
```json
"prepublishOnly": "pnpm build",
"preversion": "pnpm test:cov"
```

Note: Keep `"prepare": "husky install"` unchanged here — it will be updated to `"husky"` in Task 4 when husky v9 is installed.

- [ ] **Step 4: Update .husky/pre-commit**

Replace the full file with:
```sh
#!/bin/sh
. "$(dirname "$0")/_/husky.sh"

pnpm run pretty-quick
```

- [ ] **Step 5: Install dependencies with pnpm**

Run:
```bash
pnpm install
```
Expected: `node_modules` created, `pnpm-lock.yaml` updated.

- [ ] **Step 6: Verify tests still pass**

Run:
```bash
pnpm test
```
Expected: All tests pass (jest still in use at this point).

- [ ] **Step 7: Commit**

```bash
git add pnpm-lock.yaml package.json .husky/pre-commit
git rm yarn.lock
git commit -m "chore: migrate from yarn to pnpm"
```

### Task 2: Replace microbundle with vite

**Files:**
- Create: `vite.config.ts`
- Modify: `package.json` (scripts, fields, devDependencies)
- Modify: `tsconfig.json`

- [ ] **Step 1: Install vite and vite-plugin-dts, remove microbundle and rimraf**

Run:
```bash
pnpm add -D vite vite-plugin-dts
pnpm remove microbundle rimraf
```

- [ ] **Step 2: Create vite.config.ts**

Create `vite.config.ts` at project root with this content:

```ts
/// <reference types="vitest" />
import { defineConfig } from 'vite';
import dts from 'vite-plugin-dts';

export default defineConfig({
  plugins: [dts({ rollupTypes: true })],
  build: {
    outDir: 'lib',
    lib: {
      entry: 'index.ts',
      formats: ['es', 'cjs'],
      fileName: (format) => `use-undo.${format === 'es' ? 'mjs' : 'cjs'}`,
    },
    rollupOptions: {
      external: ['react', 'react-dom'],
    },
  },
});
```

Note: The `/// <reference types="vitest" />` and `test` config will be added in Task 3. Include the reference now so the file doesn't need restructuring later.

- [ ] **Step 3: Update package.json fields**

Remove these fields:
- `"source": "index.ts"`
- `"umd:main": "lib/use-undo.umd.js"`

Update these fields:
```json
"main": "lib/use-undo.cjs",
"module": "lib/use-undo.mjs",
"types": "lib/index.d.ts",
"exports": {
  ".": {
    "import": {
      "types": "./lib/index.d.ts",
      "default": "./lib/use-undo.mjs"
    },
    "require": {
      "types": "./lib/index.d.ts",
      "default": "./lib/use-undo.cjs"
    }
  }
}
```

Update build script:
```json
"build": "vite build"
```

- [ ] **Step 4: Update tsconfig.json**

Change `"jsx": "react"` to `"jsx": "react-jsx"`.

- [ ] **Step 5: Run the build**

Run:
```bash
pnpm build
```
Expected: `lib/` directory contains `use-undo.mjs`, `use-undo.cjs`, and `index.d.ts`.

- [ ] **Step 6: Verify build output files exist**

Run:
```bash
ls -la lib/
```
Expected: `use-undo.mjs`, `use-undo.cjs`, `index.d.ts` present.

- [ ] **Step 7: Commit**

```bash
git add vite.config.ts package.json tsconfig.json pnpm-lock.yaml
git commit -m "chore: replace microbundle with vite for library builds"
```

### Task 3: Replace jest with vitest

**Files:**
- Delete: `jest.config.js`
- Modify: `vite.config.ts` (add test config)
- Modify: `package.json` (scripts, devDependencies)

- [ ] **Step 1: Install vitest and related deps, remove jest deps**

Run:
```bash
pnpm add -D vitest @vitest/coverage-v8 jsdom
pnpm remove jest ts-jest @types/jest
```

- [ ] **Step 2: Add test config to vite.config.ts**

Add the `test` property to the `defineConfig` object in `vite.config.ts`:

```ts
/// <reference types="vitest" />
import { defineConfig } from 'vite';
import dts from 'vite-plugin-dts';

export default defineConfig({
  plugins: [dts({ rollupTypes: true })],
  build: {
    outDir: 'lib',
    lib: {
      entry: 'index.ts',
      formats: ['es', 'cjs'],
      fileName: (format) => `use-undo.${format === 'es' ? 'mjs' : 'cjs'}`,
    },
    rollupOptions: {
      external: ['react', 'react-dom'],
    },
  },
  test: {
    globals: true,
    environment: 'jsdom',
  },
});
```

- [ ] **Step 3: Update test scripts in package.json**

```json
"test": "vitest run",
"test:cov": "vitest run --coverage",
"test:watch": "vitest"
```

- [ ] **Step 4: Delete jest.config.js**

Run:
```bash
rm jest.config.js
```

- [ ] **Step 5: Run tests**

Run:
```bash
pnpm test
```
Expected: All tests pass with vitest. The test files use only `describe`, `it`, `expect`, `afterEach`, and `@testing-library/react` APIs — all compatible with vitest globals.

- [ ] **Step 6: Run tests with coverage**

Run:
```bash
pnpm test:cov
```
Expected: Coverage report generated successfully.

- [ ] **Step 7: Commit**

```bash
git rm jest.config.js
git add vite.config.ts package.json pnpm-lock.yaml
git commit -m "chore: replace jest with vitest"
```
